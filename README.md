 Valery – Aplicação Web

 Sobre o projeto
A aplicação Web do Valery faz parte do desenvolvimento de uma plataforma de comércio eletrônico voltada à venda de joias. O sistema foi desenvolvido como parte do Projeto Integrado Multidisciplinar (PIM IV), do curso de Análise e Desenvolvimento de Sistemas da UNIP.

Seu objetivo é oferecer aos usuários uma plataforma intuitiva para navegar pelos produtos, consultar informações e realizar compras online.

Funcionalidades
- Cadastro e autenticação de usuários.
- Visualização e pesquisa de produtos.
- Organização de produtos por categorias.
- Consulta de detalhes e preços dos produtos.
- Carrinho de compras.
- Realização e acompanhamento de pedidos.
- Gerenciamento de produtos e informações administrativas.

 Tecnologias utilizadas
*C#, JavaScript, CSS, HTML.*

Integração com o sistema
A aplicação Web se comunica com a API do projeto, permitindo o acesso e a troca de informações com o banco de dados e os demais módulos da plataforma Valery.
